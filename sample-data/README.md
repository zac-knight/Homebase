# Sample data

Made-up data that is safe to publish. Nothing here comes from a real browser.

| File | Used by |
| --- | --- |
| `bookmarks.json` | The extension's demo mode (`npm run dev`), backend tests, the evaluation script |
| `search-queries.json` | The evaluation script: 50 queries, each with the bookmarks that should be found |

Your own exports belong in `data/` at the repository root, which is git-ignored.
